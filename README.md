# Blockbloom1.0 TEST
Native Java/Canvas Android8+ Chocona-style puzzle. Match A/B/C/D room shade totals while every edge-connected dark component is a filled rectangle. Rectangles may cross room borders and touch at corners. Gold + is fixed dark and o fixed white. Twelve unique 4x4 clue boards, undo/reset, saved block palette/shade marks and GG007 menu/site/privacy.

Independent Java pairwise bounding-box fill and BFS oracle exhausts 65,536 masks per board against production area/bounding-box and bitset floodfill, confirming unique solutions. Bounds/fixed tiles/toggle/solve/undo/replay and adapter navigation/settings/privacy/taps/persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime/performance/browser handoff QA incomplete. Not final or Play published.
